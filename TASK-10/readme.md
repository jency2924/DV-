## Task 10 - House Price Visualization, Spatial Analytics & Real-Estate Insights

**Dataset:** King County House Sales Dataset (`kc_house_data.csv`)

**Completed Work:**

* Loaded and explored the preprocessed King County house sales dataset.
* Created scatter plots to analyze the relationship between living area and house prices.
* Applied linear regression trend lines to visualize price relationships.
* Used LOWESS smoothing to examine nonlinear trends between living area and house prices.
* Created box plots to compare house price distributions across different property grades.
* Analyzed house price differences based on waterfront status.
* Created geographic scatter plots using latitude and longitude, with house prices represented through color mapping.
* Identified high-value geographic location groups using rounded latitude and longitude coordinates.
* Calculated average price, median price, house count and average living area for each location group.
* Visualized the top 10 high-value location groups using bar charts.
* Generated real-estate investment insights based on property characteristics and geographic price patterns.
